# Math Game Project Status

## 現状の目的
ユーザーから、算数（小学1〜3年）から数学（大学1〜4年）までの問題を出題するゲームの作成を依頼されました。
要件には、3問1セットのゲームフロー、正解数に応じたコイン獲得、コインを消費してのシールガチャ、獲得したシールを閲覧できるシール帳機能が含まれています。
また、APIエラーによるアプリの停止を防ぐため、現在はフロントエンドでのローカル問題生成を基本とし、将来の拡張用にAPI側のフォールバック設定を残しています。

## 完了したアクション
1. **フロントエンドの実装**:
   - React + Tailwind CSS を使用し、「Geometric Balance」テーマ（太いボーダー、ハードシャドウ、メリハリのある色彩）を適用しました。
   - 難易度選択、問題解答(3問1セット)、リザルト画面、スコア履歴画面、ガチャ画面、シール帳画面を作成しました。
   - 答えの全角・半角、不要な空白や単位の自動正規化判定を実装しました。
2. **データ保存・認証**:
   - Firebase Auth (Google Sign-in) を用いて認証機能を実装しました。
   - スコア履歴およびコイン・シール（報酬データ）は、仕様変更に従いFirestoreではなく `localStorage` に保存するように修正しました。これにより、オフラインやAPI制限時でも動作します。
3. **ゲームエンジン・問題生成**:
   - `App.tsx` 内に難易度に応じたローカル問題生成ロジック (`mathGen`) を実装し、APIの429エラーに依存せずに継続して遊べるようにしました。
   - `server.ts` の `/api/problem` エンドポイントにも、完全なフォールバック処理（エラー時は固定問題を返す）を追加し、将来のAPI化に備えました。Gemini API呼び出し時の `ThinkingLevel.HIGH` の型エラーも修正済みです。
